# رلهٔ تلگرام

رلهٔ مشترک انتشار تلگرام سیمان‌باز، آهن‌حساب و ملک‌دان. طرح و قرارداد صف: `D:\moshtarak\RESANE.md` بخش ۴-الف.

- کد: `rele.py` (فقط کتابخانهٔ استاندارد پایتون)
- زمان‌بند: `.github/workflows/rele.yml` (دو پنجرهٔ انتشار تهران، هر ۱۵ دقیقه، و اجرای دستی)
- رازهای هر پروژه در Secrets همین مخزن، با پیشوند نام پروژه: `SIMANBAZ_SITE`، `SIMANBAZ_RELE_KEY`، `SIMANBAZ_TELEGRAM_TOKEN`،
  `SIMANBAZ_TELEGRAM_CHANNEL`. همان `RELE_KEY` در متغیر `RESANE_RELE_KEY` سرور همان پروژه.
- افزودن پروژهٔ تازه: نام بزرگ‌شده‌اش به `matrix.p` و چهار رازش.
